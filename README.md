# CryptoNinja Cube

CryptoNinjaの6キャラクターを使った、ブラウザ向け3D絵合わせキューブです。現在は甲賀の「易・静止画」と「中・アニメ」を実装しています。

## 起動

Node.js 22を推奨。

```sh
npm ci
npm run dev
```

http://127.0.0.1:5173/ を開きます。Windowsでは `start-local.cmd` でも起動できます。このPCのみ接続可能です。ポート使用中はエラーで停止します。停止は端末でCtrl+C。

同じWi-Fiのスマホから一時確認するときは、PCで次を実行し、PCのIPv4アドレスを使ってスマホから `http://<PCのIPv4>:5173/` を開きます。WindowsファイアウォールでNode.jsのプライベートネットワーク通信を許可する必要があります。

```sh
npm run dev:lan
```

## 遊び方

- 「クラン → 難易度 → 混ぜる回数」の3画面で条件を決めます。現在選べるのは甲賀の「易」と「中」です。
- 「易」は静止画、「中」は6人それぞれの5秒アニメをループ再生します。「浮遊を止める・動きを抑える」をオンにすると動画も停止します。
- 3〜30手から混ぜる回数を指定し、1面完成または6面完成を選んで開始します。
- 全6面が未完成になるシャッフルだけを採用し、混ざった状態からすぐに始まります。
- どの面でも位置と向きが揃えばクリア。3手混ぜても1〜2手で揃えば即クリアです。
- 完成した面の9ピースだけが接合し、絵が正面を向きます。クリア後の回転・戻す操作は停止。「もう一度遊ぶ」で再挑戦できます。
- 「6面完成」は従来の操作試作。6面完成時に全体が接合します。
- PC：マスをクリックしてWASD。再選択まで軸・列は固定。W/S・A/Dは逆操作です。
- スマホ：200ms長押し後、縦横に24px以上スワイプ。直接押せる矢印もあります。
- キューブの周囲を上下左右へドラッグすると、全体を一周して眺められます。選択は金色、上下は赤、左右は緑。
- 表示サイズは小・中・大。ピースの隙間・低モーションも変更できます。
- 1面モードの「操作」はシャッフルを含まず、プレイ中の戻す操作は含みます。タイムアタックの公式スコアではありません。

## 開発・検証

```sh
npm test
npm run build
# 別端末でnpm run devを起動後（Edgeが必要）
node browser-check.mjs
node oneface-check.mjs
```

整数座標と基底でパズル状態を管理し、描画の補間回転とは分離しています。63項目の自動テストで回転・逆操作・開始配置・早期クリア・再挑戦・入口画面・難易度保持・上下左右の全体回転を検証。ブラウザでは「中」の動画6本が再生されること、低モーション時に停止すること、「易」では動画を読み込まないこと、390px幅の入口レイアウトを確認済みです。実スマホの操作感・性能は未確認です。

本番ビルドは成功しますが、大きなJSチャンクの警告が残ります。配信サイズ最適化は今後の課題です。window.__cubeは操作試作の読取診断用です。

## 素材と公開範囲

このリポジトリは、公開プレイに必要な甲賀の採用済み静止画6枚と難易度「中」の無音MP4 6本だけを `public/assets/` に収録します。その他の生成素材はGit管理対象外です。画像や動画を読み込めない場合は静止画または仮タイルへフォールバックし、案内を表示します。

咲耶だけは面全体のUVを左右反転し、ほかの5面は採用素材の向きのまま表示します。`.gitignore`では画像・動画を原則除外し、公開用の12ファイルだけを明示的に追跡します。採用画像の正本パスは制作ボルトの `CryptoNinjaCube/03_画像/02_管理/Image_Adoption_Ledger.csv`、採用動画は各キャラクターの `Adopted` フォルダです。

甲賀の3ステージでは共通BGMを使用します。配信用音源は`public/assets/koga-bgm.ogg`と`public/assets/koga-bgm.m4a`で、曲の終了後に3秒間無音を挟んで再生を繰り返します。WAV原本は制作ボルトが指すDドライブ側で管理します。

ギャラリー保存・ランキング・タイムアタック・難易度「難」・効果音は未実装。ゲームのWeb公開設定は行っていません。
