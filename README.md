# CryptoNinja Cube

CryptoNinjaの6キャラクターを使った、ブラウザ向け3D絵合わせキューブです。現在は甲賀の静止画ステージを実装しています。

## 起動

Node.js 22を推奨。

```sh
npm ci
npm run dev
```

http://127.0.0.1:5173/ を開きます。Windowsでは `start-local.cmd` でも起動できます。このPCのみ接続可能です。ポート使用中はエラーで停止します。停止は端末でCtrl+C。

## 遊び方

- 「クラン → 難易度 → 混ぜる回数」の3画面で条件を決めます。現在選べるのは甲賀の「易」です。
- 3〜30手から混ぜる回数を指定し、1面完成または6面完成を選んで開始します。
- 全6面が未完成になるシャッフルだけを採用し、混ざった状態からすぐに始まります。
- どの面でも位置と向きが揃えばクリア。3手混ぜても1〜2手で揃えば即クリアです。
- 完成した面の9ピースだけが接合し、絵が正面を向きます。クリア後の回転・戻す操作は停止。「もう一度遊ぶ」で再挑戦できます。
- 「6面完成」は従来の操作試作。6面完成時に全体が接合します。
- PC：マスをクリックしてWASD。再選択まで軸・列は固定。W/S・A/Dは逆操作です。
- スマホ：200ms長押し後、縦横に24px以上スワイプ。直接押せる矢印もあります。
- キューブの周囲を上下左右へドラッグすると、全体を一周して眺められます。選択は金色、上下は赤、左右は緑。
- 表示サイズは小・中・大。ピースの隙間・低モーションも変更できます。
- 1面モードの「操作」はシャッフルを含まず、プレイ中の戻す操作は含みます。タイムアタックの公式スコアではありません。

## 開発・検証

```sh
npm test
npm run build
# 別端末でnpm run devを起動後（Edgeが必要）
node browser-check.mjs
node oneface-check.mjs
```

整数座標と基底でパズル状態を管理し、描画の補間回転とは分離しています。62項目の自動テストで回転・逆操作・開始配置・早期クリア・再挑戦・入口画面・上下左右の全体回転を検証。ブラウザではPC操作とタッチ入力の模擬試験を実施。実スマホの操作感・性能は未確認です。

本番ビルドは成功しますが、大きなJSチャンクの警告が残ります。配信サイズ最適化は今後の課題です。window.__cubeは操作試作の読取診断用です。

## 素材と公開範囲

このリポジトリはゲームシステムのみを収録し、画像・動画は含みません。手元で利用許可のある画像を `public/assets/` に配置してください（フォルダがなければ作成）。現在の甲賀キューブは `sakuya.png`、`xiaolan.webp`、`nemu.webp`、`izuna.webp`、`uka.webp`、`oto.webp` の6枚を参照します。画像なしでも各面は仮タイルで描画されますが、画像読み込みの案内が表示されます。

咲耶だけは面全体のUVを左右反転し、ほかの5面は採用画像の向きのまま表示します。`public/assets/` と画像・動画ファイルはGit管理対象外です。ローカルの素材を誤ってPushしないでください。採用画像の正本パスは制作ボルトの `Image_Adoption_Ledger.csv` にある `destination_file` 列です。

ギャラリー保存・ランキング・タイムアタック・動画・効果音は未実装。ゲームのWeb公開設定は行っていません。
